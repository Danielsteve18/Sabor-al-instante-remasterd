# Índice de documentación

Toda la documentación del proyecto vive en `docs/`, organizada por área.

| Documento | Contenido |
|---|---|
| `docs/actas/s0.md` | Acta de capacitación del sprint S0 |
| `docs/actas/s1.md` | Verificación y acta de cierre del sprint S1 |
| `docs/infra/stack.md` | Stack, versiones y aplicaciones de gestión |
| `docs/infra/estructura.md` | Árbol de carpetas y propósito de cada una |
| `docs/infra/supabase.md` | Proyecto de Supabase, migraciones y credenciales |
| `docs/requerimientos/requerimientos-funcionales.md` | Historias de usuario y reglas de negocio |
| `docs/base-datos/modelo-datos.md` | Modelo entidad-relación y tablas |
| `docs/base-datos/rls.md` | Políticas de seguridad por fila |
| `docs/diseno/identidad-visual.md` | Paleta, tipografía y tokens de diseño |

## Convenciones

- Un documento por tema, en la carpeta del área correspondiente.
- Todo documento nuevo se enlaza desde este índice.
- Los documentos se actualizan en la misma rama que el cambio que describen.
- Las rutas de evidencia de cada issue apuntan a un archivo de esta carpeta.

## Áreas

| Carpeta | Área |

| `docs/infra/` | Infraestructura, stack, estructura y Supabase |
